# 番时记 V2

V2 提供统一的浅深主题、四页视觉设计与浏览体验改进，仍是仅在本机运行的个人追番工具。沿用 Vue 3、TypeScript **6.0.3**、Vite 与 Express，收藏 ID 和 JSON 备份继续兼容 V1。

双击项目根目录 start.cmd，访问 http://127.0.0.1:4317。从旧版本更新时先关闭旧启动窗口，执行 npm ci、npm run build，再重新启动；只刷新网页不能更新仍在运行的旧服务端代码。

## 四个页面

- **本周番表**：支持竖列与横排切换。宽度达到1200px时整周同屏，窄屏按日期查看；横排在手机上可以左右滑动。今日作品按当前时区、收藏与下一条参考排期选择，也可手动切换。
- **季度目录**：保留年份、季度、TV/Web 筛选与本季度标题/别名搜索，每页24部。1280px及以上可用图标选择每行4、5、6部；中等宽度三列，窄屏两列。翻页定位到列表标题，切换密度保留筛选与页码。
- **作品详情**：展示海报、参考排期、追番与播放入口、简介、制作阵容、中文角色及CV。简介原文默认折叠，更多角色按需展开。Bangumi评分显示分值、人数与有效排名，无评分不会显示零分。
- **我的追番**：展示未来14天内下一次参考放送；没有记录时明确显示暂无排期。保留取消追番、失联ID管理及JSON备份合并导入。

从详情返回时恢复来源页面、筛选、分页、日期与滚动位置；直接打开详情时返回番表。目录、数据或部分详情获取失败时仍能使用已有数据，并提供重试入口。

## 视觉与交互

主视觉由 [SceneBackdrop.vue](../src/components/SceneBackdrop.vue) 与 [scene-visual.css](../src/scene-visual.css) 使用SVG、CSS和真实日期绘制：日期排版、放送刻度、弧线与色面构成视觉层次，不需要生成背景大图。浅深主题采用蓝色主调，配以粉色、薄荷色与静态边缘光场。

固定标题与品牌使用本地霞鹜文楷子集，正文和作品名使用系统字体。字体来源为 [LXGW WenKai](https://github.com/lxgw/LxgwWenKai)，授权随项目提供于 [OFL-LXGWWenKai.txt](../public/fonts/OFL-LXGWWenKai.txt)。真实海报来自作品数据，缺图时显示主题占位图。

季度和追番卡片将海报、标题与资料组织在一个完整表面中。季度卡片悬浮时使用1px蓝色细线与柔光，配合轻微抬升和封面缩放。已收藏采用强调色实底与填充书签，未收藏使用浅底或半透明底与空心书签，浅深主题分别调整图标对比。

顶栏时区、主题与目录筛选使用可定制的原生select：统一圆角菜单、选中底色、勾号及键盘焦点。支持鼠标、触摸、键盘、Esc取消及点击外部关闭；不支持相关CSS的浏览器使用原生菜单。手机收紧间距并保持文字单行，900px及以下导航固定底部并预留安全区。

“排期说明”展开后，点击外部或按Esc关闭；点击内容时保持展开。其他重复说明也收进可展开区域，错误、过期、休播与保存失败仍直接提示。环境动态在离开视口、页面隐藏或启用减少动态效果时暂停；页面过渡与卡片反馈也遵守减少动态效果设置。

## 偏好与兼容

| 内容 | 保存方式 |
| --- | --- |
| 主题：跟随系统／浅色／深色 | localStorage：anime-calendar:theme，首次绘制前应用 |
| 北京／日本时区 | localStorage：anime-calendar:timezone |
| 竖列／横排番表 | localStorage：anime-calendar:weekly-layout |
| 季度每行4／5／6部 | localStorage：anime-calendar:catalog-columns，首次四列 |
| 筛选、分页、日期、返回来源与滚动 | 当前标签页的 sessionStorage：anime-calendar:browse:v1 |
| 追番收藏 | 原有 localStorage：anime-calendar:favorites:v1，备份格式仍为版本1 |

偏好存储失败时保留本次操作并说明未保存；收藏写入失败不会伪装成已保存。浏览数据刷新后会校正无效页码与日期，失联收藏ID继续保留供备份或移除。

评分复用已有的Bangumi原始详情缓存，通过 GET /api/anime/:id 返回 rating（有效评分对象或null）。详情仍按需加载、缓存24小时，所有上游请求共享两个并发名额；有效旧缓存不会被获取失败覆盖。缺少整个评分字段的旧服务会明确提示重启，来源暂无评分与请求失败分别呈现。

排期继续采用网络先行优先与既有时区规则。周期推算直接显示参考时间，来源排期、公告和休播保留标注；不再逐项显示“预计”或“已过计划时间”。时间已过不代表平台已更新，推算依据和地区限制可在展开说明、官网及平台查看。维护方式见 [README](../README.md#缓存与人工修正) 和 [数据核查](data-validation.md)。

运行验证命令和日志约定见 [开发说明](DEVELOPMENT.md)。截图与测量工具为 tests/support/visual-v2.mjs 和 tests/support/performance-v2.mjs：前者加 --live 使用正常启动的4317服务，否则与后者均使用独立固定样本服务4321。先手动启动 node tests/support/e2e-server.mjs 再运行工具，结束后停止测试服务；不要与Playwright自动管理的4321服务同时运行。

开发日志、完整截图、测量数据和已弃用的图片处理工具仅在 .local/ 中归档，不纳入Git；当前网页不依赖归档图片或脚本。远程海报加载速度与上游资料完整度取决于来源，本版本仍不包含账号、云同步、观看进度、通知、站内播放或云端部署。
